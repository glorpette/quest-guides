Face tracking

Quest Pro Only!

Enhanced face tracking is only available on a rooted Meta Quest Pro.
There are multiple projects to choose from, depending on your desired setup and platform.

Struggling to pick?

If you are unsure about the differences between the face-tracking projects, compare their features below.


Quest Pro face tracking Runs on PC QproFaceTracking V2.0.2

Enhanced face tracking (QproFaceTracking)

Set up independent eye gaze, tongue tracking, pupil dilation, and USB or wireless tracking with QproFaceTracking on a rooted Meta Quest Pro. Runs on PC and supports Windows + Virtual Desktop or Steamlink.

Guide and project by Fwooffy Read the guide →
Quest Pro face tracking Runs on headset BoltOn V0.6.0

Enhanced face tracking (BoltOn)

Set up independent eye gaze, tongue tracking, pupil dilation, and wireless tracking with BoltOn on a rooted Meta Quest Pro. Runs on headset and supports Windows or Linux + Virtual Desktop, Steamlink, WiVRn and ALVR.

Eye tracking projects feature comparison
Feature QproFaceTracking BoltOn
What sets it apart A windows only solution with more advanced hardware access, own model creation capabilities and USB support. A universal solution that runs directly on the Quest Pro; skipping processing overhead on the PC. Supports Windows and Linux, supports multiple VR streaming tools, easier setup via Singularity.
Tracking features Eye gaze, tongue tracking, and pupil dilation. Eye gaze, tongue tracking, and pupil dilation.
Where model runs Windows PC. Quest Pro (on headset).
Connectivity USB or Wireless to QproFaceTracking Hub. Wireless via streaming app.
Streamer support Virtual Desktop, Steam Link. Virtual Desktop, Steam Link*, WiVRn, ALVR, potentially others.
Tracking output VRCFaceTracking. Direct to VRChat or through VRCFaceTracking.
PC OS compatibility Windows. Windows and Linux.

* In Direct to VRChat mode only.
