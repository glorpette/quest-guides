BETA! BoltOn is in beta and is rapidly evolving. Changes and improvements will happen over time. BoltOn contains an automatic update feature, so only an initial setup is required.

Before you start: you need a rooted Meta Quest Pro. This program will not work on an unrooted headset or a different Quest model. If you still need to root your Quest Pro, use one of the root guides available on the homepage. Check that your headset's exact software version is supported by Singularity before following a root guide.

BoltOn has multiple modes. BoltOn can be ran in Direct or VRCFaceTracking mode. Direct mode uses OSC over your streamer app to communicate directly to VRChat without the need for additional Software. VRCFaceTracking mode communicates to VRCFT over the streamer app and requires the VRCFaceTracking software to be installed on your PC through Steam.

Other streamers may be supported. BoltOn has been tested with Virtual Desktop, Steamlink, WiVRn and ALVR. Other streamers that expose face tracking traffic may also be compatible.

We want YOU!

BoltOn is looking for contributors to upload datasets to help further improve the facial tracking models! The more data, the better the algorithm will become. More info will be posted here when available.

Start by installing BoltOn onto your Quest Pro. This app will communicate to either VRCFT or VRChat directly, via your streamer app.

Set up eye tracking and independent gaze first

  1. On the rooted Quest Pro, open Settings > Movement Settings. Turn on Eye Tracking and Natural Facial Expressions, then run eye calibration if offered. If these are already enabled, leave them on.
  2. If Magisk OverlayFS is not installed yet, open Singularity > Apps/Modules > Magisk repo and install it. Follow any reboot prompts. If it is already enabled in Magisk, you can skip reinstalling it.
  3. In the same Singularity menu, install Quest Pro Independent Eye Gaze if it is not installed yet. Reboot if prompted, then check in Magisk that both modules are enabled. This is the headset-side independent gaze route.

Installation

Install and Set up BoltOn

  1. Open Singularity and install the BoltOn app from Apps/Modules.

    2. Alternative Method 1

    Open the Browser app on your Quest Pro and visit tinyurl.com/BoltOnVR to download the APK file. (This link redirects to GitHub and downloads the latest release APK automatically)

    Alternative Method 2

    Download the latest BoltOn APK file from this project's Releases page. Choose the named BoltOn APK, not GitHub's “Source code” ZIP. Transfer the APK file to your Quest Pro via USB.


    Once the APK is on your headset, open the Files app and navigate to the APK file. Tap the hamburger menu and select Open with, and choose Package Installer. Alternatively, APKs can be installed from inside Singularity.

    Follow the prompts to install BoltOn. If you see a warning about installing apps from unknown sources, allow it and confirm that you want to proceed.


  2. Once installed, open the BoltOn Calibrator app. You should be prompted to grant superuser permission from Singularity-Magisk for the app, please allow it.
  3. Once the app is opened, click Install Magisk Module to install the required tracking module. Please restart your headset after installation finishes to apply it.

No prompt?

If you dont get a prompt, open the Singularity-Magisk app, go to the Superuser section and grant permission to the BoltOn Calibrator.

Don't see the app after install?

The app may not appear in your main app list. Search for BoltOn in the app drawer and choose BoltOn Calibrator.

Calibration

Calibrate Face Tracking

This section will guide you through the process of calibrating face tracking for optimal performance. Some users find that the default model works well, while others may need to calibrate for better accuracy.

  1. Switch to the Calibration tab in the BoltOn Calibrator app.
  2. Follow the on-screen instructions to perform the calibration. This will involve making facial expressions.
  3. Once calibration is completed, click Save to save the new profile to the device.
  4. Test the face tracking in the Live Preview tab, or your desired application to ensure it is working as expected. If you encounter issues, you may need to repeat the calibration process.

Configuration

Selecting BoltOn Mode

BoltOn has two modes of operation: Direct and VRCFaceTracking. Direct mode communicates directly with VRChat, while VRCFaceTracking mode communicates with the VRCFT software on your PC. Both methods communicate through your chosen VR streaming application (such as Virtual Desktop, Steam Link, WiVRn, etc).

Use this table as a starting point; recommendations can depend on your setup.

BoltOn mode recommendations by VR streamer
Streamer Direct VRCFT
Virtual Desktop Supported Recommended, use VD Module
Steam Link Supported Not supported
ALVR / ALXR / WiVRn Not supported Supported, use ALXR Local Module*
Other / unlisted Try first Try if Direct doesn't work

* With VRCFT and an ALXR-protocol streamer such as ALVR or WiVRn, enable FBFaceTrackingV2TongueHack in VRCFT's local ALXR module config for tongue tracking. Failure to do this will result in the tongue not tracking. If you are on Linux, that is at /home/<username>/.config/VRCFaceTracking/CustomLibs/<generated id>/ALXRModuleConfig.json

To select a mode, open the Settings tab in BoltOn Calibrator and choose Direct or VRCFT. BoltOn starts in VRCFT mode by default.

If a mode is not working with your streamer, try the other mode where the table indicates it may be suitable.

Help

Troubleshooting

What you seeWhat to try
“Root access unavailable”Keep the Quest awake. In Magisk, allow Shell / ADB Shell, then refresh the connection.
Wireless stopped working after a rebootCheck the Quest's current Wi-Fi address. Wireless ADB may need to be enabled again.
Independent gaze or convergence fails but ordinary face tracking worksCheck the Quest's exact firmware build. Follow the Singularity Magisk setup in section 1; it has been reported working on Horizon OS v2.7.
Tongue disappears in some positionsCheck that your calibrated model is loaded in Profiles. You may need to recalibrate in the BoltOn calibrator app.

If you need help, you can ask in the Meta Quest Rooting Support Group Discord. The server is not owned by Walaryne.
